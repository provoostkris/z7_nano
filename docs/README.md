## 🧠 What Is the Zynq-7020?

The Zynq-7020 is a **System on Chip (SoC)** that combines:
- A **dual-core ARM Cortex-A9 processor** (for software tasks)
- A **programmable logic (FPGA)** section (for hardware tasks)

This allows you to build systems where software and hardware work together seamlessly.
